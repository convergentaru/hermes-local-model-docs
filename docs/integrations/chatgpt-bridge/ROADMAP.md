# Roadmap — ChatGPT Bridge

## Фаза 0. Зафиксировать исходное состояние

- [ ] Зафиксировать текущую версию AI Free и Git commit.
- [ ] Зафиксировать Hermes version/config schema без обновления.
- [ ] Проверить процессы, listeners и занятые порты AI Free / Hermes.
- [ ] Проверить, какой браузерный профиль и режим авторизации использует AI Free.
- [ ] Снять безопасный baseline логов без вывода секретов.
- [ ] Подтвердить, что локальный модельный endpoint продолжает работать.

**Gate 0:** есть воспроизводимый снимок исходного состояния; ничего не изменено.

## Фаза 1. Исследовать исходный код и документацию

- [ ] Изучить ChatGPT provider в установленной версии AI Free.
- [ ] Проследить цепочку login → browser profile → challenge detection → chat request → response.
- [ ] Изучить AI Free API: endpoint, модели, streaming, ошибки, таймауты, лимиты.
- [ ] Сопоставить это с `hermes-chatgpt-web-cli` и актуальным `hermes-web-clis`.
- [ ] Проверить официальную документацию Hermes по custom OpenAI-compatible providers.
- [ ] Отделить документированные свойства от заявлений автора и собственных наблюдений.

**Gate 1:** есть таблица возможностей и ограничений каждого варианта.

## Фаза 2. Исследовать Cloudflare / Turnstile

- [ ] Определить, какой именно challenge возникает в нашем сценарии.
- [ ] Установить, где проходит проверка: видимый браузер, отдельный browser context или фоновый запрос.
- [ ] Проверить, сохраняется ли авторизованная сессия между перезапусками.
- [ ] Проверить, что происходит при истечении cookies/session.
- [ ] Проверить различие между успешной загрузкой ChatGPT UI и успешным API-like запросом из браузерной автоматизации.
- [ ] Описать штатную процедуру ручной проверки и восстановления.

**Ограничение:** проект не реализует обход CAPTCHA/Turnstile, подмену fingerprint или извлечение/перенос clearance-токенов между несовместимыми браузерными контекстами.

**Gate 2:** документирован безопасный и воспроизводимый login/re-auth flow; неизвестные ограничения явно перечислены.

## Фаза 3. Проверить AI Free как основной транспорт

- [ ] Выполнить штатную ручную авторизацию ChatGPT через предусмотренный AI Free flow.
- [ ] Проверить ChatGPT provider внутри AI Free UI/CLI.
- [ ] Проверить локальный OpenAI-compatible `/v1/models`.
- [ ] Выполнить минимальный `/v1/chat/completions` тест.
- [ ] Проверить streaming и non-streaming.
- [ ] Проверить multi-turn, timeout, ошибки авторизации и rate limit.
- [ ] Проверить, что API слушает только локальный интерфейс, если внешний доступ не требуется.

**Gate 3:** AI Free самостоятельно стабильно отвечает через локальный API.

## Фаза 4. Подключить Hermes

- [ ] Сверить актуальный синтаксис custom provider с установленной версией Hermes.
- [ ] Добавить отдельный профиль/провайдер ChatGPT Bridge, не заменяя рабочий локальный профиль.
- [ ] Проверить модельный список и минимальный запрос.
- [ ] Проверить tool calling отдельно от обычного текстового ответа.
- [ ] Проверить длинный ответ, streaming, timeout и восстановление после ошибки.
- [ ] Сравнить работу Hermes через ChatGPT Bridge и через текущую локальную модель.

**Gate 4:** Hermes использует ChatGPT через AI Free; локальный провайдер остаётся доступным.

## Фаза 5. Стабильность и эксплуатация

- [ ] Проверить поведение после перезапуска AI Free.
- [ ] Проверить поведение после перезапуска браузера/системы.
- [ ] Проверить истечение сессии и штатное повторное подтверждение.
- [ ] Измерить latency, частоту ошибок и долю успешных запросов.
- [ ] Определить безопасные лимиты параллельности и частоты.
- [ ] Подготовить runbook диагностики и восстановления.

**Gate 5:** есть проверенная эксплуатационная инструкция и понятные ограничения.

## Фаза 6. Решение о дополнительном адаптере

- [ ] Если AI Free не обеспечивает требуемую стабильность, выполнить отдельный изолированный proof-of-concept для Hermes Web CLI/CDP.
- [ ] Не запускать два конкурирующих браузерных профиля одновременно без необходимости.
- [ ] Сравнить сложность сопровождения, совместимость и устойчивость.
- [ ] Выбрать один основной путь; второй оставить резервным только при доказанной пользе.

**Gate 6:** принято решение на основании тестов, а не предположений.

## Definition of Done

- [ ] ChatGPT отвечает через AI Free API.
- [ ] Hermes получает ответы через отдельный custom provider.
- [ ] Текущая локальная модель и её endpoint не сломаны.
- [ ] Повторная авторизация описана и проверена.
- [ ] Измерены latency, ошибки и устойчивость сессии.
- [ ] Все существенные решения и тесты занесены в журнал.
- [ ] В репозитории отсутствуют cookies, токены, профили браузера и секреты.
