# Research — ChatGPT Bridge

Дата первичного обзора: 2026-11-11. Это предварительный обзор публичных README, не аудит исходного кода и не результат запуска на целевой машине.

## 1. lesterppo/hermes-chatgpt-web-cli

Источник: https://github.com/lesterppo/hermes-chatgpt-web-cli

Публичный README описывает небольшой Python CLI для ChatGPT Web, предназначенный для Hermes Agent. В репозитории на момент просмотра видны три основных файла: `README.md`, `chatgpt.py`, `chatgpt_tool.py`; GitHub показывает один commit.

README заявляет:
- Playwright + Chrome browser profile;
- отдельный `--login` для видимого браузера;
- последующие запросы в headless режиме;
- сохранение состояния профиля;
- Cloudflare Turnstile как ключевое ограничение.

Важная оговорка: формулировка автора о том, что Turnstile «auto-resolves», не является гарантией. На практике challenge зависит от текущей политики Cloudflare/OpenAI, браузерного контекста, сетевой среды и состояния сессии. Успешный вход не доказывает, что все последующие запросы пройдут.

Предварительная оценка: полезный минимальный proof-of-concept и источник идей, но не следует сразу принимать его за production-ready решение.

## 2. lesterppo/hermes-web-clis

Источник: https://github.com/lesterppo/hermes-web-clis

README описывает более развитую коллекцию CLI и несколько транспортных подходов. Для ChatGPT указан headed Chromium/CDP и долговременно живущий браузерный профиль. Автор отдельно предупреждает, что headless режим может вызывать Cloudflare/DOM-проблемы.

Это важный архитектурный сигнал: для ChatGPT предпочтительнее исследовать реальный видимый браузерный контекст, а не рассчитывать на извлечение cookies и перенос clearance между браузерами.

README содержит меняющиеся технические заявления и дату изменений; их необходимо сверить с текущим исходным кодом и собственными тестами перед использованием.

## 3. AI Free

Источник: https://github.com/Staks-sor/ai-free

Локальная копия пользователя — отдельный fork/clone: https://github.com/convergentaru/ai-free

README описывает:
- ChatGPT как одного из поддерживаемых web providers;
- отдельные browser profiles / local sessions для провайдеров;
- локальные desktop UI и CLI;
- OpenAI-compatible и Anthropic-compatible API;
- API endpoint, который в README указан как локальный сервис на порту 4318 (проверить именно установленную версию и фактическую конфигурацию).

Это делает AI Free наиболее логичным первым кандидатом: он уже является частью существующего стека и потенциально решает задачу адаптера без добавления ещё одного самостоятельного browser automation проекта.

## 4. Cloudflare / Turnstile: рабочая модель

Нужно различать:
1. загрузку страницы ChatGPT;
2. появление и прохождение challenge;
3. сохранение авторизованного состояния в конкретном browser profile;
4. отправку последующего сообщения;
5. получение ответа из того же контекста;
6. повторяемость всего цикла после перезапуска и истечения сессии.

Нельзя считать шаги 1–3 доказательством успешности шагов 4–6.

Планируется использовать только штатный интерактивный login flow и поддерживаемый браузерный контекст. Не предпринимать автоматическое решение CAPTCHA, обход challenge, подмену browser fingerprint или перенос clearance-токенов между контекстами.

## 5. Предварительная матрица вариантов

| Вариант | Сильная сторона | Неизвестное / риск | Приоритет |
|---|---|---|---|
| AI Free ChatGPT provider → local API → Hermes | Уже установлен в рабочем стеке; единый локальный API | Реальная стабильность ChatGPT provider и API в текущей версии | 1 |
| lesterppo/hermes-chatgpt-web-cli | Минимальный специализированный CLI | Небольшой репозиторий; headless после login может быть ненадёжен | 2 |
| lesterppo/hermes-web-clis (CDP) | Более развитая схема с headed browser/CDP | Дополнительный daemon/profile и сопровождение | 3 |
| Официальный OpenAI API | Поддерживаемый API-контракт | Это отдельный платный API, не ChatGPT Web session | Вне основной цели, контрольный вариант |

## 6. Что пока НЕ известно

- Текущая версия и локальные изменения AI Free на машине.
- Фактический порт API и команда запуска.
- Работает ли ChatGPT login в установленной версии сейчас.
- Какой конкретно Cloudflare challenge наблюдается.
- Работает ли запрос к ChatGPT provider после успешного login.
- Совместимы ли streaming/tool-calling ответы AI Free с Hermes в текущей конфигурации.
- Как Hermes текущей версии принимает custom OpenAI-compatible endpoint.

Эти вопросы закрываются фазами 0–4 Roadmap.
