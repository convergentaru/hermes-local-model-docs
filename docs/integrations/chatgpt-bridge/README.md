# ChatGPT Bridge — проект интеграции ChatGPT с Hermes

Статус: **исследование / проектирование**  
Дата создания: 2026-11-11  
Основной стек: Ubuntu + AI Free + ChatGPT Web + Cloudflare Turnstile + Hermes Agent

## Цель

Проверить и реализовать устойчивый, воспроизводимый способ использовать ChatGPT через локальный интерфейс AI Free и подключить его к Hermes Agent. Отдельно исследовать альтернативные браузерные адаптеры для Hermes, включая `lesterppo/hermes-chatgpt-web-cli`.

**Целевой маршрут (гипотеза, подлежит проверке):**

```
ChatGPT Web session
       │
       ▼
AI Free (browser session + provider adapter)
       │
       ▼
AI Free OpenAI-compatible local API
       │
       ▼
Hermes Agent (custom OpenAI-compatible provider)
```

Это не утверждённая архитектура до прохождения проверок. Альтернативный маршрут через отдельный Hermes CLI/CDP-адаптер исследуется отдельно.

## Принципы

1. Сначала исследование и read-only аудит; затем изменения по одному.
2. Не обновлять Hermes, AI Free и браузерные зависимости без отдельного обоснования.
3. Не останавливать работающую локальную модель и существующие сервисы.
4. Не обходить CAPTCHA/Turnstile и антибот-защиту. Использовать штатную авторизацию в видимом браузере, если провайдер требует ручной проверки.
5. Разделять подтверждённые факты, гипотезы и результаты экспериментов.
6. Не сохранять в Git cookies, токены, пароли, профили браузера, .env и реальные ответы с приватными данными.
7. Не считать успешный вход в браузере доказательством работоспособности последующих запросов: отдельно проверять весь путь до API-клиента.

## Объект исследования

- [AI Free](https://github.com/Staks-sor/ai-free) — локальный клиент с ChatGPT provider и OpenAI-compatible API.
- [Hermes ChatGPT Web CLI](https://github.com/lesterppo/hermes-chatgpt-web-cli) — небольшой CLI, использующий Playwright и постоянный профиль браузера.
- [Hermes Web CLIs](https://github.com/lesterppo/hermes-web-clis) — более широкий набор веб-адаптеров; README описывает headed Chrome/CDP для ChatGPT.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) — целевой агент, который должен потреблять совместимый API.

## Критерий успеха

Hermes отправляет тестовый запрос через AI Free API, получает ответ от ChatGPT Web provider, сохраняет корректную работу текущего локального провайдера и не требует повторной ручной авторизации на каждом обычном запросе. Устойчивость сессии, ограничения частоты, восстановление после истечения сессии и поведение Turnstile должны быть отдельно измерены.
