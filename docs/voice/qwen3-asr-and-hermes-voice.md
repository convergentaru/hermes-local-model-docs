# Голос: Qwen3-ASR-0.6B, STT и TTS в Hermes

Обновлено: 2026-10-10.

## Что уже работает

В разделе Voice Unsloth Desktop пользователь загрузил **Qwen3-ASR-0.6B**. Русское распознавание проверено и, по оценке пользователя, работает очень хорошо.

Это подтверждает локальную транскрипцию внутри Unsloth. **Это не означает, что Hermes Desktop уже использует Qwen3-ASR.**

## Роли компонентов

- **STT (speech-to-text):** аудио → текст. Для этой задачи работает Qwen3-ASR-0.6B в Unsloth.
- **LLM:** Hermes передаёт текстовое задание выбранной языковой модели (во время проверки — Qwen3.5-4B через Unsloth).
- **TTS (text-to-speech):** текст ответа → речь. Требуется отдельный TTS-провайдер или модель.

## Что видел пользователь в Hermes Desktop

- Voice Chat Mode: `Chained` и `GPT Live` / варианты duplex.
- Speech-to-Text включён.
- Проверка/подтверждение транскрипции включена.
- Локальные модели STT: `base`, `small`, `medium`, `large-v3` (варианты Whisper).
- Язык транскрипции изначально не задан.
- Есть отдельный раздел Text-to-Speech, выбор провайдера и голоса.

Точный список названий TTS-провайдеров не был зафиксирован скриншотом; не угадывать названия и не менять параметры наугад.

## План интеграции

### 1. Сначала — штатный STT Hermes

Для отдельной проверки интерфейса: оставить `Chained`, включить STT и выставить Russian/Русский, если доступно. Проверить короткую фразу. Это проверяет встроенный путь Hermes, а не Qwen3-ASR.

### 2. Затем — интеграция Qwen3-ASR с Hermes (если нужно)

Нужно проверить актуальный endpoint Unsloth для audio transcription, формат запроса, авторизацию и поддержку этого endpoint в Hermes. Сам факт успешного распознавания в Studio не подтверждает полную совместимость API.

### 3. Затем — TTS

Выбрать реально доступный в установленной версии Hermes провайдер TTS и проверить короткий ответ по-русски. Не считать ASR-модель синтезатором речи.

## Память и режим исполнения

В Unsloth пользователь видел режимы исполнения аудиомодели на RAM/CPU либо на GPU, если доступно; фактически выбранный режим Qwen3-ASR в истории не зафиксирован. Qwen3.5-4B в том же сеансе занимала 11,425 MiB из 12,288 MiB VRAM. Поэтому не загружать Qwen3-ASR на GPU параллельно без замера; вариант RAM/CPU может экономить VRAM, но скорость нужно проверить.

## Приоритет пользователя — аудио раньше обновления модели (2026-10-31)

Пользователь подтвердил порядок работ:
1. Сначала завершить текущую задачу по аудио/голосу.
2. Только после этого возвращаться к выбору и загрузке более крупной модели.

До завершения аудио-задачи:
- не скачивать Qwen3.8-27B или другую новую модель;
- не менять текущую Qwen3.5-9B и её рабочую конфигурацию;
- не запускать вторую модель параллельно;
- не предполагать, что конкретный аудиоподэтап уже выбран этим сообщением.

После завершения аудио вернуться к записке `docs/model-selection/2026-10-31-upgrade-candidates.md`. Сначала проверить доступную память и локальное наличие прежней Qwen3.6-35B-A3B; только затем решать вопрос о скачивании Qwen3.8-27B. Контекст 160K остаётся целевым критерием, а не параметром, который следует автоматически снижать ради более крупной модели.
