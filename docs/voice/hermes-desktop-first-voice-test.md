# Первый голосовой разговор с Hermes Desktop

Цель: проверить цепочку по отдельным этапам — микрофон, распознавание речи (STT), ответ выбранной LLM и озвучивание (TTS).

## 1. Проверить модель

В Unsloth Desktop:
1. Убедись, что загружена именно Ministral 3 8B, а не просто выбрана в библиотеке.
2. Для текущей конфигурации проверь Context Length = 65536, Parallel Slots = 1 и KV Cache = q8_0 (если этот вариант выбран).
3. Отправь короткий запрос: `Ответь ровно: MINISTRAL_8B_READY`.
4. Не переходи к голосовой проверке, если прямой запрос не сработал.

## 2. Запустить Hermes Desktop

Официальная команда:

~~~bash
hermes desktop --cwd "$HOME/robot-factory-os"
~~~

Она запускает Desktop в каталоге Robot Factory OS. Она сама по себе не меняет провайдера или API-ключ. Если Desktop уже открыт, продолжай в его текущем окне.

Launcher-скрипт: [scripts/start-hermes-desktop.sh](https://github.com/convergentaru/hermes-local-model-docs/blob/main/scripts/start-hermes-desktop.sh).

Официальная документация: https://hermes-agent.nousresearch.com/docs/user-guide/desktop

## 3. Проверить текстовый маршрут

В Hermes Desktop открой Settings → Models (название вкладки может немного отличаться). Сохрани проверенное подключение Unsloth: `http://127.0.0.1:8888/v1`. Выбери точный идентификатор модели, которая реально загружена в Unsloth. В списке API раньше была `ministral-3-8b`, но сверь это с текущим списком. Не меняй ключ, если авторизация уже работает.

В новой сессии отправь: `Ответь ровно: HERMES_MINISTRAL_TEXT_OK`.

Если появится `No model loaded`, проверь состояние Loaded/Running в Unsloth и загрузку модели. Не переустанавливай CUDA и не меняй ключ. Если текст работает, переходи к настройке голоса.

## 4. Настроить распознавание речи

В Settings → Voice:
- Voice Chat Mode: **Chained**.
- Speech-to-Text (STT): включить.
- Transcript confirmation: включить на время проверки.
- Language: Russian / `ru`, если доступно.
- Из доступных локальных Whisper моделей начни с `base`; если качество слабое, проверь `small`.

Скажи короткую фразу по-русски, например: «Гермес, сегодня мы проверяем голосовой режим». Проверь, что показанный текст соответствует сказанному. Сначала подтверди транскрипцию, затем проверь ответ модели.

Не выбирай GPT Live для первого теста: это отдельный full-duplex сервис, который требует OpenAI API и может тарифицироваться по времени сессии.

## 5. Проверить озвучивание

TTS настраивается отдельно. Если доступен установленный локальный голосовой движок (например, Piper, NeuTTS или KittenTTS), выбери его и проверь короткий ответ. Если доступен только Edge или другой облачный провайдер, сообщи пользователю, что текст ответа может отправляться внешнему сервису, и получи согласие до включения. Не называй облачный TTS локальным.

## Отчёт

Отметь по отдельности PASS / FAIL / NOT TESTED:
1. Ministral 3 8B загружена в Unsloth.
2. Прямой запрос Unsloth прошёл.
3. Hermes отвечает через выбранную модель.
4. Микрофон работает.
5. STT распознаёт русскую речь.
6. Hermes отвечает на распознанную речь.
7. TTS озвучивает ответ.

Полная голосовая цепочка считается проверенной только если этапы 4–7 реально прошли. Qwen3-ASR-0.6B из Unsloth не считается подключённой к Hermes до отдельной проверки API.

## Ограничения безопасности и ресурсов

Не выводи ключи или содержимое `~/.hermes/.env`. Не запускай параллельно вторую тяжёлую LLM. На этом компьютере около 11 GiB системной RAM и RTX 3060 12 GB VRAM; при резком замедлении не запускай дополнительные модели. Сначала стабилизируй текстовый маршрут, затем подключай Screenpipe.
