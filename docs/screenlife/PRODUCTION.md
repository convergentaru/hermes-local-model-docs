# Production notes — Screenlife AI Agents

## Формат

Современная Screenlife-история, раскрывающаяся через цифровые интерфейсы: терминал, браузер, чаты, API-вызовы, окна приложений, файлы и курсор.

Вдохновение — киноязык Screenlife, развиваемый Тимуром Бекмамбетовым. Проект самостоятельный; не копировать чужие сцены, персонажей, музыку, дизайн или монтажные решения.

## Драматургический принцип

Каждая сцена начинается с одинакового задания для двух агентов. Зритель наблюдает не только ответы, но и процесс: источники, выбранные инструменты, ошибки, смену стратегии, проверку фактов, оформление результата и время выполнения.

Различия не инсценировать. Если агенты выбирают похожий путь, так и оставить.

## Пилотная последовательность

1. **Загрузка общей модели.** Один Unsloth llama-server; Hermes и Claude Code подключаются через разные API-совместимые интерфейсы.
2. **Системный аудит.** Hermes выдал аккуратную таблицу; Claude Code запустил 9 shell-команд и показал дополнительные параметры, но часть вывода была повреждена.
3. **Осенние листья.** Сравниваются структура, объяснение пигментов и научная аккуратность.
4. **Погода в Амстердаме.** Hermes выдал сводку с названиями источников. Claude Code показал цепочку Fetch: 404 → 404 → 301 → Open-Meteo 200 → timeout при повторной попытке. Финальные данные Claude были частично повреждены.
5. **Раскрытие общей модели.** Два агента использовали одну Qwen3.5-9B; различия возникали из агентской среды, toolset и инструкций.

## Capture-протокол

Перед каждой сессией зафиксировать дату/время, версии агентов, модель/quantization, контекст, parallel slots, протоколы API и включённые tools/MCP.

Во время:
- записать общую картину рабочего стола;
- записать отдельно окна агентов, если возможно;
- сохранить исходные prompts;
- сохранить необрезанные terminal logs и tool traces;
- записать длительность заданий;
- отметить ошибки и смены стратегии.

После:
- хранить untouched raw captures отдельно от монтажных прокси;
- transcript сохранять без исправления орфографии и повреждений;
- редакторские пояснения хранить отдельно;
- фиксировать checksums исходных видео и логов;
- не публиковать приватные окна и данные.

## Что уже есть

В архиве сессии 31.10.2026 сохранены запросы и ответы, переданные в переписку. Некоторые выводы Claude Code были частично повреждены форматированием при копировании. Исходные видеозаписи экранов, полные сырые логи и аудиодорожки в GitHub ещё не загружены.

## Монтажный язык

- Интерфейсы должны сообщать действие, а не быть декоративными окнами.
- Временные метки, tool-call trace и переключения окон могут задавать ритм.
- При одном inference slot генерации сериализуются; не монтировать их как одновременную генерацию.
- Не добавлять агентам реплики на постпродакшене так, будто они были сказаны в исходной сессии.
- Закадровый комментарий визуально отличать от настоящего вывода агента.
