# SCREENLIFE: два агента, одна модель

**Рабочее название:** «ОДИН МОЗГ»  
**Формат:** современный Screenlife-фильм / сериал / документальный AI-эксперимент.  
**Стартовый материал:** реальная сессия 31 октября 2026 года.

## Логлайн

Два локальных AI-агента — Hermes и Claude Code — получают одинаковые задачи и решают их разными способами. Они используют одну и ту же локальную Qwen3.5-9B через один Unsloth inference server, но отличаются инструментами, системным окружением, маршрутом поиска и манерой ответа. Весь сюжет раскрывается через реальные экраны компьютера.

## Главная идея

Не изображать «искусственную личность» актёрами и не писать агентам заранее придуманные реплики. Снимать реальные действия: терминалы, браузеры, API-запросы, ошибки, паузы, ответы, исправления и сравнение результатов.

Драматургия рождается из расхождения поведения агентов при одинаковой задаче и общей модели.

## Персонажи

### Hermes
Локальный агент с собственным CLI/Gateway, навыками и инструментами. В первой погодной задаче выдал структурированный прогноз со ссылками на BBC Weather, Open-Meteo и другие источники, но без проверяемых прямых ссылок на конкретные прогнозы.

### Claude Code
Кодовый агент, подключённый к Unsloth через Anthropic-совместимый API. В погодном эксперименте показал видимую цепочку Fetch-вызовов: неудачные источники, перенаправление, успешный Open-Meteo API, повторную попытку и ошибку тайм-аута. Финальный формат частично повредился.

## Центральный парадокс

**Одна модель. Два агента. Разные маршруты.**

Модель: `Qwen3.5-9B-Q4_K_M.gguf`.  
Inference server: один Unsloth `llama-server`.  
Контекст: 160 000 токенов.  
Параллельные слоты: 1.

Hermes и Claude Code не являются двумя разными базовыми моделями. Сравнивается поведение агентских оболочек, инструкций, инструментов и маршрутизации.

## Вдохновение и самостоятельность

Вдохновение — язык Screenlife, развиваемый Тимуром Бекмамбетовым. Проект самостоятельный: не копирует фильмы, персонажей, сюжеты или визуальные решения существующих произведений.

## Правило доказательности

Различать исходный запрос, фактически показанный агентом ответ, видимые действия и инструменты, независимую оценку и гипотезы о причинах поведения. Не приписывать агенту действия, которых нет в записи. Не выдавать пересказ или оценку за исходный transcript.
