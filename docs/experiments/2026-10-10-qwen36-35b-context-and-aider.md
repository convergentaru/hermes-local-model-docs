# Отчёт: Qwen3.6-35B-A3B, контекст и Aider

Сеанс: 9–10 октября 2026. Статус: исторический эксперимент. Не повторять запуск 64K на текущем оборудовании.

## Конфигурация

- Модель: `/home/oleg/models/Qwen3.6-35B-A3B-UD-IQ2_XXS.gguf` (~10.7 GB).
- GPU: RTX 3060 12 GB VRAM.
- RAM: около 11 GiB; swap 4 GiB.
- Бинарник: `/home/oleg/llama.cpp/build-cublas/bin/llama-server`.
- Скрипт: `~/local-llm-stack/experiments/qwen3.6-35b/run.sh`.
- Порт: `8999`.

## Хронология и результат

1. Скрипт сначала запускал сервер с `-c 4096`.
2. Hermes сообщал, что окно 4096 ниже минимального 64,000 токенов, необходимых для текущего пути агента.
3. Выполнена команда `hermes config set compression.enabled false`. Она отключила конфигурацию compression в CLI, но сама по себе не сняла проверку минимального контекста основной модели.
4. Попытка `-c 65536` привела к зависанию компьютера; скрипт вернули из резервной копии.
5. Попытка `-c 8192` успешно запустила llama-server; лог сообщал `n_ctx_slot = 8192`. После этого сервер остановили, чтобы освободить ресурсы для Unsloth/Qwen3.5-4B.
6. Aider успешно создал простой `hello.py` при 4096 токенах.
7. Для задачи WordPress при окне 4096 был превышен размер запроса: 4191 токен.
8. При окне 8192 длинный запрос/ответ заняли около 9,738 токенов, то есть больше 8,192; ответ модели также содержал длинное рассуждение.

## Не повторять

- Не запускать `-c 65536` на Qwen3.6-35B с нынешними 11 GiB RAM / 12 GiB VRAM.
- Не держать эту модель параллельно с другой крупной GPU-моделью при почти заполненной VRAM.
- Не считать обучающий контекст модели её гарантированным рабочим контекстом на конкретном компьютере.
- Не считать, что увеличение контекста в клиенте увеличивает окно на стороне сервера.

## Резервные копии

Во время правки создавались `run.sh.bak` и `run.sh.bak-4096-<timestamp>`. Перед дальнейшим изменением проверить список `ls -lt ~/local-llm-stack/experiments/qwen3.6-35b/run.sh*` и прочитать содержание существующих копий. Не восстанавливать файл наугад.

- Для основного Hermes уже есть более компактный рабочий маршрут через Unsloth + Qwen3.5-4B.
- Для кода Aider пригоден только с ограниченным набором файлов и короткими заданиями.
