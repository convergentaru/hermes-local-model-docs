# NEXT_ACTION — один следующий шаг

Дата: 2026-10-31

## Текущая задача

Восстановить прежний запуск одной модели Qwen3.5-9B через графический интерфейс Unsloth Desktop/Studio, затем подключить Claude Code.

## Следующий шаг — только GUI Unsloth

1. Открыть Unsloth Desktop/Studio обычным способом из меню приложений.
2. Не запускать Hermes и не выполнять `unsloth start claude ...`.
3. Найти существующую модель `Qwen3.5-9B-Q4_K_M.gguf` по пути:
   `/home/oleg/.hermes/models/Qwen3.5-9B-Q4_K_M.gguf`.
4. Открыть существующие параметры/профиль модели. Не менять их до фиксации исходных значений.
5. Передать ChatGPT снимок экрана или точный список видимых настроек.

**Остановиться после просмотра профиля.** Не нажимать Start/Load, пока параметры не записаны и не сверены.

## После этого

- загрузить одну модель с восстановленными настройками;
- выполнить короткий тест непосредственно в Unsloth;
- записать фактический порт worker, параметры контекста, RAM/VRAM и результат;
- только после успешного теста подключать Claude Code штатным способом, восстановленным из локальной конфигурации и справки установленной версии.

## Не делать

- не повторять ошибочную команду `unsloth start claude --model ... --max-seq-length ...`;
- не запускать Hermes model server параллельно;
- не скачивать и не перемещать модель;
- не менять контекст на 115K/160K по памяти без чтения GGUF metadata и текущего профиля;
- не переустанавливать Unsloth, llama.cpp или Claude Code;
- не запускать несколько терминалов и длинные диагностические сценарии.
